# KaijTab 人工验收清单

> 自动化已覆盖的部分见 README（38 单测 + 21 E2E）。下面这些是自动化难以覆盖、需要手工确认的项目。
> 每项前打勾即可；发现问题的记在最后一节。

## 0. 准备

- [ ] `pnpm build` 无报错，`dist/` 存在
- [ ] `chrome://extensions` 开发者模式加载 `dist/`，无红色错误
- [ ] 新标签页打开即显示 KaijTab（搜索框 + 快捷方式，居中排布）

## 1. 画布手感（核心体验）

- [ ] 齿轮进入编辑态：元件出现虚线框，壁纸变暗
- [ ] 拖动搜索框：跟手、不抖、松手后位置保留
- [ ] 靠近其他元件的边/中线时出现蓝色参考线并自动吸附
- [ ] 按住 Alt 拖动：吸附关闭，可以自由落点
- [ ] 拖动四角与四边手柄缩放：不跑位、不翻转，最小值有钳制
- [ ] 点击元件自动置顶；右键菜单置顶/置底/复制/锁定/删除/设置都生效
- [ ] 锁定后无法拖动但仍能操作元件内容（试试锁定搜索框后点击输入）
- [ ] 方向键微移 1px，Shift+方向键 10px
- [ ] Ctrl+Z / Ctrl+Shift+Z 撤销重做，连续拖 5 次后能一路退回
- [ ] 把窗口从 1080p 拖到 4K 或超窄：元件不跑丢、不飞出可视区；恢复窗口后回到原位
- [ ] 删除元件后能通过"模块/添加"找回（搜索框与快捷方式也是可删可加）

## 2. 动态壁纸（含真实 Wallpaper Engine 素材）

- [ ] 导入 1 个真实 WE 视频壁纸（文件方式）：播放正常、无音轨、循环
- [ ] "从壁纸引擎导入"指向 `steamapps/workshop/content/431960/`：能列出并批量导入，名称取 `project.json` 的 title
- [ ] 导入中进度条推进；中途关掉面板不影响其他功能
- [ ] 导入一个超大文件（>300MB）有性能提示；>500MB 被拒绝
- [ ] 导入一个异常/损坏视频：给出明确错误，不产生半成品文件（壁纸库无残留）
- [ ] 同一文件导入两次：提示疑似重复（选择继续或跳过）
- [ ] 4K 视频作为壁纸：拖动元件时帧率仍稳定（任务管理器看 GPU/CPU 不飙高）
- [ ] 切到后台标签页：视频暂停，CPU 占用下降；切回来继续播
- [ ] 播放设置三项开关逐一验证（隐藏暂停 / 仅聚焦播放 / 编辑态变暗）
- [ ] 删除使用中的壁纸：要求先切换后才允许删除；删除后 OPFS 占用下降（面板底部数字）
- [ ] 导出壁纸：文件能正常下载并播放
- [ ] "清理孤儿文件"：正常时提示无孤儿；手工制造（改 storage 删索引）后能清掉

## 3. 模块机制
- [ ] 模块中心：「时钟」出现在可用模块，启用/停用状态正确
- [ ] 添加时钟：先出现骨架（一闪而过正常），然后正常走时；秒针每秒更新
- [ ] 时钟右键 → 设置：关掉"显示秒"、切 12 小时制，立即生效并持久化
- [ ] 停用一个有实例的模块：弹出确认，确认后实例被删除
- [ ] 打开 DevTools → Network，刷新后检查：**未放置时钟时不加载 `clock-*.js` chunk**
- [ ] `pnpm new:module demo` 生成的骨架能 build 并出现在模块中心

## 4. 搜索与快捷方式

- [ ] 三个引擎切换后回车跳转正确（Bing/百度/Google）
- [ ] **点引擎名展开下拉：三项全部完整可见**（不再被元件边框裁掉），点任意一项能切换
- [ ] **输入关键词：下方弹出建议**——第一行是「用 X 搜索「xxx」」，接着是**当前引擎的在线联想词**（🔍），最后是命中的浏览历史与书签（书签带 ★）
- [ ] 输入"贴吧"这类词：能看到引擎的联想词（如"贴吧工具箱""贴吧网页版登录入口"）
- [ ] 切换引擎后再输入：联想词换成新引擎的（Bing / 百度都试一下；Google 在国内容易超时，失败时只显示本地建议，属预期）
- [ ] 把网络断开再输入：只显示本地历史/书签建议（不报错、不卡住）
- [ ] 建议里按 ↑/↓ 能高亮移动，回车进入选中项；Esc 关闭建议；点空白处也能关
- [ ] 输入一个从没访问过的词：提示"没有匹配的历史或书签"，回车仍能正常搜索
- [ ] 输入 `bilibili.com` 回车直接跳转该站点（而不是搜索它）
- [ ] 添加快捷方式：名称留空也能保存（用网址当名字）；图标自动获取、失败时显示首字母
- [ ] 编辑/删除快捷方式即时生效
- [ ] 快捷方式数量超出元件尺寸时表现合理（网格排布不溢出、不遮挡）

## 5. 数据与同步

- [ ] 关闭同步时：`chrome.storage.sync` 无 `sync:*` 键
- [ ] 开启同步：`chrome.storage.sync` 出现 `sync:meta` 与分块；改动布局 1 秒后会重新写入
- [ ] 关闭同步：云端键被清除
- [ ] 用同一浏览器账号的第二个 Chrome 配置文件登录后，能看到同步过来的布局（壁纸回落默认背景并有提示）
- [ ] 手工把布局改到很大（20+ 元件）再开同步：超配额时自动关闭并弹提示，本地数据完好
- [ ] 清空浏览器缓存后打开新标签页：本地数据仍在（说明我们存在扩展存储里）

## 6. 边界与回归

- [ ] 连续开关编辑器 10 次，无状态错乱
- [ ] 同时打开两个新标签页，都改布局（会互相覆盖，属预期）；不会崩
- [ ] 卸载重装扩展后：本地数据清空（预期），无残留报错

## 7. 外观（玻璃 / 缩放 / 图标）

- [ ] 设置 → 外观：切「无 / 磨砂玻璃 / 液态玻璃」，全部元件外观即时变化
- [ ] **磨砂玻璃**：背景被明显糊化、整体偏乳白（不应把深色壁纸衬得"发彩"），顶部有一条 1px 亮边
- [ ] **液态玻璃**：在**有细节的壁纸**（照片/视频）上能看到边缘的**轻微折射扭曲**；顶部亮环 + 左上斜向反光可见
- [ ] 液态玻璃叠在**高饱和/霓虹**壁纸上：文字仍然清楚（深色下有一层炭灰暗纱）
- [ ] 把脸贴近屏幕看：材质里有极细的颗粒（不是纯色块，也不该看到明显噪点）
- [ ] 元件拖大拖小：玻璃材质跟着铺满，边框与高光不拉伸变形、不闪烁
- [ ] 深浅色切换后玻璃材质仍然成立（浅色是白色系、深色是炭灰系）
- [ ] 单个元件右键 → 设置 → 玻璃效果选「无」：只有它变回原样式，其他元件仍是全局效果
- [ ] 时钟拖大 2~3 倍：时分秒与日期等比放大，不溢出、不裁切；拖小后等比缩小
- [ ] 搜索框与快捷方式拖大：字号/图标跟着变大，快捷方式列数随宽度变化
- [ ] 网站图标：百度 / B站 / 知乎 / 微博 显示真实品牌图标（浅色圆角底）
- [ ] 网速差时：图标位置先显示首字母，4 秒内加载成功会替换成真图标
- [ ] 站点不提供标准路径图标时显示首字母色块（而不是破图或灰色地球）
- [ ] 给某个快捷方式在编辑弹窗里填一个自定义图标地址，保存后立刻生效

## 8. 新模块（便签 / 待办 / 倒计时 / 天气 / 书签）

- [ ] 便签：输入文字 → 右下角出现"已保存 HH:MM" → 刷新页面文字还在；调字号/对齐即时生效
- [ ] 便签：**输入框里按 Ctrl+Z 只撤销文字**，不会撤销画布布局
- [ ] 待办：添加 3 条、勾选 1 条 → 进度显示 `1 / 3`；"清除已完成"只删已完成项
- [ ] 待办：添加后**立刻刷新页面**，条目还在（数据立即落盘）
- [ ] 倒计时：把日期改成明天 → 显示 `1`；改成今天 → 显示"就是今天 🎉"；开启"每年重复"后跨年不会变成负数
- [ ] 天气：默认北京能拉到真实数据（温度/天气文案/今日高低温/体感/湿度/风）
- [ ] 天气：把城市改成"上海"→ 重新获取；改成不存在的城市 → 显示"找不到城市"并可重试
- [ ] 天气：断网（或禁用网络）→ 显示上次数据 + 错误提示 + 重试按钮，不白屏
- [ ] 书签：模块显示书签栏内容；点文件夹能进入、能返回；在浏览器里新增书签，模块**不用刷新就出现**
- [ ] 书签：来源切换到"其他书签"能看到对应内容

## 9. 网站导航图标摆放（自由摆放）

- [ ] 编辑态右键网站导航 →「排列图标」：出现排列工具条，导航处于排列态
- [ ] 拖动任意图标：跟手、可拖到任意位置；靠近其他图标/边缘出现参考线并自动吸附
- [ ] 按住 Alt 拖动：吸附关闭，可自由落点
- [ ] 拖到导航框外：自动贴边钳制，不会拖丢
- [ ] 排列中途按 Esc 或点「完成」：退出排列模式；**没拖动过任何图标时不应写入位置数据**
- [ ] 「恢复自动排列」：图标回到整齐网格
- [ ] 排列后刷新页面：位置保留
- [ ] **把导航元件拉大/缩小**：整组图标按比例跟随缩放，相对排布不乱
- [ ] 自由摆放状态下新增一个网站：新图标落在现有图标下方一行（不是插进网格里）
- [ ] 排列后的位置随账号同步到另一台设备（需开启同步）

## 10. 主题（深色 / 浅色 / 跟随系统）

- [ ] 设置 → 外观 · 主题：三档都能切换，界面立即变化
- [ ] 「跟随系统」下改 Windows 的浅色/深色设置：界面自动跟着变（无需刷新）
- [ ] 浅色模式下逐项检查：玻璃质感（磨砂/液态）、默认背景渐变、搜索框、便签/待办/书签/天气卡片、图标底色、滚动条、编辑态参考线，都不应是"深色残留"
- [ ] 浅色 + 液态玻璃下文字仍然清晰（不发灰、不糊）
- [ ] 主题设置能持久化（刷新后保持），并随账号同步到另一台设备

## 11. 壁纸格式

- [ ] 导入 `.mov` / `.mkv` 等非白名单视频：能解码就正常播放，不能则给出明确错误
- [ ] 导入 GIF 动图作为壁纸：正常循环播放
- [ ] 导入 SVG 作为壁纸：正常显示（缩略图不糊、不报错）
- [ ] 导入网页壁纸（WE 的 web / application 工程文件夹）：能渲染、动效运行
- [ ] 网页壁纸里的相对路径资源正常：样式生效、外链 JS 执行、纹理/fetch 正常
- [ ] 工程若含内联 `<script>`：导入时提示"N 段内联脚本已外置"，渲染后脚本效果正常

## 12. AI 推荐（自接接口）

- [ ] 模块 → 添加「AI 推荐」：未配置时显示接入表单（含隐私说明）
- [ ] 三项留空点保存：提示"三项都要填"
- [ ] 点「预览将发送的数据」：能展开 JSON，**检查里面没有完整 URL、没有查询串**（只有域名、标题、书签域名、快捷方式名）
- [ ] 填真实接口（如 `https://api.openai.com/v1` + 模型 + Key）保存：浏览器弹出该域名授权，同意后开始生成
- [ ] 推荐列表出现：图标、标题、理由可读；点击能打开对应站点
- [ ] 右上角 ⟳ 能强制刷新；显示的"x 分钟前"随时间更新
- [ ] **每次打开新标签页都会重新生成**（连开两次新标签页，观察接口被调用两次、推荐内容刷新）
- [ ] 打开时右上角短暂显示"正在生成…"，1–3 秒内出结果（低思考档位应明显更快）
- [ ] 若接口返回 400（不认识思考控制字段）：自动降级重试一次后仍能出结果，标题栏显示"已降级"
- [ ] 让模型做长推理的场景（如 deepseek-reasoner）明显变慢属正常——换成非推理模型更快
- [ ] 把接口地址改成错的（如 `https://api.openai.com/v2`）→ 显示 HTTP 错误原因 + 重试按钮
- [ ] 故意填错 Key → 提示里包含"API Key 或权限可能不对"
- [ ] 断网后刷新 → 显示错误但不白屏；恢复网络后重试成功
- [ ] 配置持久化：刷新页面后仍是已配置状态，直接显示上次推荐
- [ ] **隐私核查**：设置里开启账号同步后，用 `chrome.storage.sync` 检查**没有 API Key**（`localSecrets` 不上云）
- [ ] 换设备（同一浏览器账号）：接口地址与模型名同步过来，Key 需要重新填（预期）
- [ ] 本地模型（如 Ollama `http://localhost:11434/v1`）：授权后也能用
- [ ] **垃圾核查**：把 AI 推荐元件删掉 → `chrome.storage.local` 里 `moduleData` 不再有 `ai-recommend:` 开头的键
- [ ] **垃圾核查**：便签/待办元件删掉后，`moduleData` 里同样不留残留键（可配合"壁纸占用/清理孤儿文件"一起看）
